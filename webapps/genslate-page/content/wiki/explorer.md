> [!IMPORTANT]
> Explorer is **planned**. This page describes the design it is being built to; details may change
> before the first release. The picture on its [app page](/apps/explorer/) is a live preview built
> from the design kit.

Explorer is a calm, fast file manager that opens your portable folders first, so the files on your
drive feel like home on any computer.

## Planned features

- **Source-list sidebar.** Favourites (your portable Desktop, Documents, Downloads, Music, Pictures and
  Videos), locations and colour tags.
- **Grid, list and tree views**, remembered per folder, with sortable columns.
- **Search as you type** across the current folder tree, with filters for kind, size and date.
- **Quick look.** <kbd>Space</kbd> previews images, text, Markdown and code in a side inspector.
- **Batch rename** with patterns and a live preview of every result.
- **Tabs** and a breadcrumb path bar you can type into.

## Works with the suite

Double-click opens files in the matching GENSLATE app — photos in Gallery, music in Jukebox, notes in
Editor — and the Launcher's `/folder` command opens Explorer at a portable folder.
