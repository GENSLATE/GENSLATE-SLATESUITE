GENSLATE grows one app at a time, each built on the same design system, settings format and
portable folder layout.

## Available as a preview

- **Launcher** — search, favourites, three app sources, slash commands, portable folders, tray,
  global shortcut, hot-reloaded settings.
- **Design Kit** — every design-system component in every state, in both Nord themes.

## Next for the Launcher

- Run it on Windows, macOS and Linux and polish the details on each.
- Bundle icons for every app from the GENSLATE icon family.
- Suite packaging: `bun run package --suite` and a light Windows installer for those who want one.
- Builds for four targets from continuous integration.

## Open questions

- **Code signing** for Windows and macOS, so the first launch needs no extra confirmation.
- **Automatic updates**, which depend on signing.

Ideas and feedback are welcome in the [issue tracker](https://github.com/genslate/GENSLATE/issues).
